# Penta Freight Frontend

A responsive frontend web application built for Penta Freight.

## Tech Stack & Purpose

- **React**: Used to build the core UI components and manage state.
- **Vite**: Used as the frontend build tool and development server for fast compiling.
- **Tailwind CSS**: Used for all styling, layout structuring, and ensuring mobile responsiveness.
- **Framer Motion**: Used to create scroll-triggered animations and the dynamic number counting effect.
- **Swiper**: Used to create the automated, infinite-looping carousel for the certifications section.
- **Lucide React**: Used for rendering vector icons across the UI (like the mobile hamburger menu).

## Installation & Commands

**1. Install all required packages**
```bash
npm install
```

**2. Start the local development server**
```bash
npm run dev
```

**3. Create a production build (Outputs to `/dist` folder)**
```bash
npm run build
```
